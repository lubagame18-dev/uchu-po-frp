# Страница базы знаний

`index.html` — двухколоночный просмотр: слева таблица/схема, справа её текст.

Запуск локально из корня проекта:

```bash
python -m http.server 8099
```

Откройте `http://127.0.0.1:8099/knowledge/index.html`.

`manifest.json` связывает каждую тему с изображением и текстом. Исходные PDF и полные скриншоты лежат в `knowledge-base/`; на боевой сайт эта папка не копируется из-за размера, чтобы не раздувать Object Storage.
