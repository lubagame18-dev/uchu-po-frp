# База знаний — веб-версия

`knowledge/web/` — облегчённая версия для сайта: только сгенерированные таблицы-изображения и `manifest.json`.
Полные исходники и оригинальные скриншоты лежат в `knowledge-base/` (в репозитории, не выкладываются в Object Storage из-за размера).

Запуск локально:

```bash
python -m http.server 8099
```

Откройте `http://127.0.0.1:8099/knowledge/index.html`.
