## Конспекты по русскому языку — свой формат для каждого раздела (`js/rukit.js`)

- Морфология, фонетика, морфемика — свои приёмы и задания. Рабочий лист и слайды получают ту же теорию, алгоритм, раздаточные тексты и таблицу.

## Что сделать нельзя и чем это заменено

- **GitHub Models:** GitHub закрыл сервис 30.07.2026. Основной бесплатный вариант теперь OpenRouter (вход без прокси).
- **Pollinations без ключа:** сервис больше не выдаёт тексты анонимно. Нужен ключ или вход через приложение (см. инструкцию).
- **Системный прокси с логином и паролем в браузере:** страница не может направить свои запросы через прокси компьютера. Вместо этого используется сервер-посредник `proxy.js` с адресом, портом, логином и паролем. Split Tunneling выбирает, какие нейросети идут через него.
- **Письма прямо с сайта:** у статического сайта нет своего почтового сервера. Используется FormSubmit (бесплатно, нужно один раз подтвердить почту); при сбое файл скачивается сам.
- **Инфоурок как источник для сверки:** у сайта нет открытого API, со сторонних страниц его читать нельзя. Сверка идёт по Википедии и Викитеке, на Инфоурок даются ссылки на поиск.
- **Пароль на статическом сайте:** хранится хэш SHA-256 с солью, а не сам пароль. Это защита от случайного входа. Защитой от специалиста она не является: код сайта открыт всем.
- **Файлы пользователей у разработчика:** без сервера браузер одного учителя не видит браузер другого. Файлы приходят на почту, разработчик загружает их в «Файлы от пользователей».
