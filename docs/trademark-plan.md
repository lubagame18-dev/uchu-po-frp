# Товарный знак «Учу по ФРП» — план регистрации

## 1. Проверка
- Реестры Роспатента: fips.ru (открытые реестры).
- Поиск в Google/Яндекс, Telegram, маркетплейсах.

## 2. Классы МКТУ
- 41 — обучение и образовательные услуги (основной).
- 42 — разработка и предоставление ПО / SaaS.
- 35 — реклама и продвижение (по желанию).
- 16 — печатные учебные материалы (по желанию).

## 3. Подача
- Портал: www1.fips.ru (электронные сервисы) или патентный поверенный.
- Заявление: заявитель, обозначение «Учу по ФРП», классы МКТУ, описание.
- Пошлины (электронно): заявка ~3 500 ₽ + 1 000 ₽ за класс свыше 1; регистрация ~16 000 ₽ + 1 000 ₽ за класс свыше 1. Ориентир 20–30 тыс. ₽ без поверенного.
- Срок: формальная экспертиза ~1 мес., экспертиза по существу 4–6 мес., всего до 8–12 мес.

## 4. До регистрации
- Использовать ™, после регистрации — ®.
- На сайте: «© 2026 Учу по ФРП. Все права защищены».

## 5. Подготовить
- Логотип (ч/б и цветной), начертание «Учу по ФРП».
- Скриншоты использования (сайт, материалы, даты).
- Документы заявителя (самозанятый/ИП/ООО).
