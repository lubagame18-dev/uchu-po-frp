# Мониторинг копирования материалов

## Регулярно
- Google Alerts: «Учу по ФРП», «uchu-po-frp», «конструктор уроков по ФРП».
- Яндекс.Мониторинг — те же фразы.
- Поиск в Telegram/ВК: «конспекты ФРП», «рабочий лист ФРП».
- Маркетплейсы: Ozon, WB, Авито, Boosty, Инфоурок, Мультиурок.

## Ежемесячно
- Copyscape/Text.ru — уникальность страниц.
- Яндекс.Картинки — поиск ваших изображений.
- Проверка выгрузок: в .docx стоит «© Учу по ФРП · для: email · дата».

## Если нашли копию
1. Скриншот, URL, дата, кто разместил.
2. Требование удалить владельцу/хостингу.
3. Жалоба в поисковик (форма авторских прав) и на маркетплейс.
4. При продаже копий — защита прав после получения свидетельства на товарный знак.
