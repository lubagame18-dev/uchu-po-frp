- В GitHub-деплое обе базы знаний уже исключались. В локальном PowerShell-деплое
  и Cloudflare .assetsignore исключений не было: добавлены.
- GitHub и PowerShell используют общий deploy/site-excludes.txt: закрыты
  knowledge-base/, knowledge/, deploy/, tools/, серверные каталоги,
  Python/PowerShell/shell-скрипты, логи, .env и служебные файлы.
- Убрано --size-only, пропускавшее изменённые файлы прежнего размера.
  Обычный aws s3 sync сравнивает размер и время; свежий checkout может
  перезаливать неизменённое. Оптимизация по хешам остаётся отдельной задачей.

- PowerShell проверяет код возврата каждой команды AWS и не сообщает об успехе
  после ошибки внешнего процесса.
