# Планы ФРП 2025 — что добавлено и как откатить

Сгенерировано из официальных ФРП 2025 (см. `data/frp2025/report.md`).

## Как работает

1. `js/plans-loader.js` при выборе предмета, после загрузки старых модулей, грузит `data/frp2025/index.js`.
2. Если предмет включён в `UCHU_FRP2025.subjects`, грузится `data/frp2025/<предмет>.js` и его классы
   **поштучно** перекрывают `window.FRPPlans[предмет][класс]`.
3. Классы, которых нет в 2025-модуле, остаются из старых `frpplans*.js` (фолбэк).
4. Литература: `data/frp2025/lit.js` → `window.UCHU_FRP_PLANS2025.lit`; `FRP.topicsFor` и `FRP.planFor`
   в `js/app-part1.js` отдают эти данные приоритетно (остальные rich-данные не тронуты).

## Проверки

- Валидатор: индексы `l → s/th`, непустые темы — 0 ошибок (71 класс, 4753 урока).
- Слияние со старыми планами: ни один класс не потерян (симуляция), всего 7374 урока.
- `node --check` для `plans-loader.js`, `app-part1.js`, `sw.js` — без ошибок.

## Откат

- Быстрый: в `data/frp2025/index.js` убрать предмет из `UCHU_FRP2025.subjects[предмет]`.
- Полный: удалить `data/frp2025` из `sw.js` (SHELL) и вернуть `VERSION`; старые модули не менялись.
- Литература: удалить `data/frp2025/lit.js` из SHELL; `FRP` вернётся к `data/frp.js`.
