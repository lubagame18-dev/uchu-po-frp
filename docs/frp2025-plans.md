# Планы ФРП 2025 — что добавлено и как откатить

Сгенерировано из официальных ФРП 2025 (см. `data/frp2025/report.md`).

Покрыто: **16 предметов, 107 классов, 8332 уроков**; литература 5–11 — rich-слой.

## Как работает

1. `js/plans-loader.js` грузит `data/frp2025/index.js` после старых модулей.
2. Классы предмета из `data/frp2025/<предмет>.js` **поштучно** перекрывают `window.FRPPlans`.
3. Классы без 2025-данных остаются на старых `frpplans*.js` (фолбэк).
4. Литература — `window.UCHU_FRP_PLANS2025.lit`, приоритет в `FRP.topicsFor/planFor`.

## Проверки

- Валидатор модулей: индексы `l → s/th`, пустые темы — 0 ошибок.
- Живой сайт: выбор темы проверен в браузере (физкультура 4, английский 4, биология 10, литература 5, математика 7 и др.).
- `node --check` для изменённых JS — без ошибок.

## Откат

- Быстрый: убрать предмет из `UCHU_FRP2025.subjects` в `data/frp2025/index.js`.
- Полный: удалить `data/frp2025` из SHELL в `sw.js` и вернуть `VERSION`.

## Осталось (на старом плане)
ОБЖ/ОБЗР и ОРКСЭ — в официальных ФРП нет поурочного планирования (только модульное ТП),
поэтому оставлены старые поурочные планы сайта; вероятность и статистика, МХК, астрономия —
отдельных ФРП нет, сайт собирает их сам.
