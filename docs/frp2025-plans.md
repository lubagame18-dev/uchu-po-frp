# Планы ФРП 2025 — что добавлено и как откатить

Официальные ФРП 2025 + типовые школьные рабочие программы там, где в ФРП нет поурочного планирования.
Покрыто: **18 предметов, 112 классов, 8502 уроков**; литература 5–11 — rich-слой.

## Как работает

1. `js/plans-loader.js` грузит `data/frp2025/index.js` после старых модулей.
2. Классы предмета из `data/frp2025/<предмет>.js` **поштучно** перекрывают `window.FRPPlans`.
3. Классы без новых данных остаются на старых `frpplans*.js` (фолбэк).
4. Литература — `window.UCHU_FRP_PLANS2025.lit`, приоритет в `FRP.topicsFor/planFor`.

## Пометка по ОБЖ и ОРКСЭ

В официальных ФРП по ОБЖ/ОБЗР и ОРКСЭ есть только тематическое планирование (модули), поурочного нет.
Для 8–11 и ОРКСЭ 4 уроки взяты из типовых школьных рабочих программ (34 урока на класс) —
это не официальный федеральный документ, при обновлении ФРП их стоит заменить.

## Проверки

- Валидатор модулей: индексы `l → s/th`, пустые темы — 0 ошибок.
- Живой сайт: выбор темы проверен в браузере (математика 9–11, физкультура 4, литература 5 и др.).
- `node --check` для изменённых JS — без ошибок.

## Откат

- Быстрый: убрать предмет из `UCHU_FRP2025.subjects` в `data/frp2025/index.js`.
- Полный: удалить `data/frp2025` из SHELL в `sw.js` и вернуть `VERSION`.

## Осталось
Вероятность и статистика, МХК, астрономия — отдельных ФРП нет, сайт собирает их сам.
