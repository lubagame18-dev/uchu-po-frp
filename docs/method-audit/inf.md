## Редактура опор

### Информация и кодирование

- При фиксированной длине кода i бит существует 2ⁱ разных кодовых слов. Чтобы закодировать N символов, подберите наименьшее целое i, при котором 2ⁱ ≥ N.
- Для равномерного кода сравни размер алфавита с числом двоичных слов выбранной длины.
- Хватит ли четырёх бит на символ для алфавита из 17 знаков? Какова минимальная длина равномерного двоичного кода? — Четыре бита дают 16 кодов, пять — 32. Для 17 знаков нужно не менее 5 бит на символ.

### Системы счисления

- Значение целого числа — сумма разрядных слагаемых. У правой цифры вес 1, а при каждом шаге влево вес умножается на основание.
- При переводе натурального числа последовательно делите его на новое основание. Остатки прочитайте от последнего к первому.
- Объясни, почему 101₂ равно 5₁₀. Покажи вклад каждого разряда. — 1 · 4 + 0 · 2 + 1 · 1 = 5. Цифра 0 на позиции с весом 2 показывает, что двоек в разложении нет.

### Алгоритмы

- Для ветвления проверь обе ветви и значение на границе условия. Запиши вход, выбранную ветвь и выход.
- Исполнитель выводит «да», если x > 5, иначе «нет». Что он выведет для 4, 5 и 6? — Для 4 — «нет», для 5 — «нет», для 6 — «да». Равенство 5 проверяет границу строгого условия.

### Базы данных

- Ключ может состоять из одного поля или из сочетания полей. Значение ключа однозначно определяет запись таблицы.
- В таблице кружков один ученик может заниматься в разных кружках, но записывается в каждый только один раз. Подойдёт ли пара «код ученика, код кружка» как ключ? — Да. Каждый код по отдельности может повторяться, а их пара однозначно определяет запись.
