# Математика

В Chromium собраны конспект занятия, рабочий лист и промт через действующий предметный модуль на всех 1418 позициях. Для сравнения в той же версии сайта подставлены прежние три математических модуля из 9aa8b38b. Названия, номера и классы сохранены. Изменение текста одного или нескольких материалов зафиксировано на 799 позициях.

| Классы и темы | Учебный материал и порядок работы |
|---|---|
| 1–4. Сложение, вычитание, деление | Выложить две группы фишек, объединить и убрать одну группу. Для деления сравнить 12 фишек в трёх равных группах с разбиением на группы по три. Объяснить, что обозначает частное в каждом случае. |
| 1–4. Доли, величины | Сравнить четверть и половину двух равных полосок наложением. Перед сравнением длины 1 м и 95 см привести обе к сантиметрам. Дать обратную связь по выбору действия и способу проверки. |
| 5–9. Дроби, проценты, уравнения | Сравнить сумму и произведение дробей, проверить допустимость делителя. Найти скидку до вычитания из исходной цены. Для уравнения ax + b = 0 отдельно рассмотреть случай a = 0. |
| 7–11. Степени, тригонометрия, стереометрия | Разделить основание и показатель степени; у тангенса проверить ненулевой знаменатель. На модели прямоугольного параллелепипеда показать три ребра из одной вершины, вычислить объём и записать результат в см³. |
| 10–11. Первообразная, интеграл, логарифмы | Проверить первообразную дифференцированием. В задаче на общий вид записать константу; при нахождении геометрической площади проверить знак функции. Перед преобразованием логарифма назвать ограничения на основание и аргумент. |
