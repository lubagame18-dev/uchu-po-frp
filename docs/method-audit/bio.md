# Биология

Исправлены задания о хлоропластах, составе выдыхаемого воздуха и пути крови. По рисунку кожицы луковицы ученик различает обязательный для данной клетки признак и признак фотосинтезирующей ткани. Уточнены путь воздуха через глотку и механизм вдоха.

Клетка — рассмотреть рисунок кожицы сочной луковичной чешуи, отметить клеточную стенку и обосновать вывод независимо от наличия зелёных пластид. Дыхание — сопоставить состав двух проб воздуха, затем по схеме альвеолы объяснить направление перехода газов. Кровообращение — провести стрелки от желудочка до предсердия, проверить название сосуда по направлению кровотока.

Проверено 310 строк действующего предметного плана. Изменение выдачи обнаружено в 29. Перечень показывает изменение выдачи резолвера по точному названию урока. Само совпадение темы с банком не подтверждает методическую уместность всех его заданий.
