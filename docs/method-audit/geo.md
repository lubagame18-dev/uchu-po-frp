# География

Уточнены четыре опоры. Широта и долгота разобраны на примере 55° с. ш., 37° в. д. Появились перевод сантиметров в километры для плана, гипотеза об источнике речного стока летом, расчёт изменения населения и задание по карте экономических районов России.

Карта и измерения — прочитать условие масштаба, измерить отрезок, записать единицы и проверить ответ обратным переводом. Гидросфера — выдвинуть гипотезу о роли подземных вод и назвать признак, по которому её можно проверить. Население — посчитать естественный и миграционный прирост порознь, затем объяснить итог. Регионы — найти район по легенде, обозначить его на карте и проверить привязку субъекта РФ.
