# Методический аудит «Учу по ФРП»

Проверены 7 134 позиции действующего планирования по 23 предметным направлениям. Русский язык и чтение начальной школы представлены отдельно. Произвольный режим «Другой предмет» проверен штатным тестом промтов; у него нет фиксированного плана.

[Поурочный реестр Excel](register.xlsx) включает класс, номер, тему, раздел, объём в часах, материал, выбранный планом, и результат сборки. Одна строка может обозначать многочасовую тему. В прогоне создали локальный черновик для каждой позиции, используя первый урок темы. Проверка текста учителем и генерация через внешнюю модель имеют другой охват.

## Что требует продолжения

- При преобразовании техкарты с заголовком «2. Блочно-модульное описание урока» сценарий терял объяснение и примеры. Конструктор теперь распознаёт обе редакции заголовка. Браузерная проверка подтверждает сохранение материалов после таблицы этапов.
- Астрономия использует тематический план, для шести уроков добавлены собственные материалы. Для семи тем МХК исправлены привязки к предметным материалам в конспекте, рабочем листе и промте.
- По литературе материалы 5 класса выборочно сверены с действующей федеральной программой. У встроенных программ разная датировка. Для подтверждения полного соответствия ФРП требуется построчная нормативная сверка для каждой дисциплины и редакции. [Официальный каталог](https://edsoo.ru/rabochie-programmy/)
- Предметные материалы в репозитории и их выкладка на домен имеют отдельные статусы. Штатная общая выгрузка синхронизирует бакет с удалением файлов и исключает каталог knowledge/.
