# Литературное чтение. 1–4 классы

В карточках сказок вопросы допускали только наличие волшебных предметов и трёхкратного повтора. Теперь ребёнок находит поступок или предмет и показывает, как изменился ход событий. Для басни проверяется связь морали с поступком независимо от её места в тексте.

При чтении стихотворения раньше к разным текстам предлагалась одна подсказка из «Берёзы». Тренировочный фрагмент теперь подписан именем автора и названием и приведён целиком в пределах заготовленного отрывка. Ученик называет чувство, указывает слово-подсказку, затем применяет приём к стихотворению урока.

В рабочем листе можно начать прогноз по заглавию без иллюстрации. Для проверки ребёнок выписывает слово, выражение или повтор. Материал находится в LitPrimary.
