## Предметная редактура и проверка

Убрано общее требование дышать при беге только через нос. Ученику даётся пример приблизительного подсчёта частоты пульса с единицей уд/мин и предлагается оценить своё самочувствие. Практика строится вокруг упражнения учителя: показ, наблюдение одного признака в паре, смена ролей и самооценка. Ограничение исходного конструктора: локальный шаблон одного общего практикума используется в разных классах; исправленные связи обеспечивают тематический материал для промта.
