# Английский язык

2–4 классы. В задании на обратный перевод раньше независимо выбирались два слова: учитель мог получить ключ из другой карточки. Теперь реплика и ответ используют одну словарную пару. На теме алфавита ребёнок соотносит букву с записью её названия; для первых шести букв дана транскрипция. В конспекте появился короткий обмен репликами для работы с карточками.

5–11 классы. В карточке Future forms разведены условия с if и время с when; для обещания добавлена речевая ситуация. В Reported Speech выбор времени и дейктических слов привязан к моменту пересказа. В Conditionals включено объяснение примера с общей закономерностью. Для выбора артикля явно задано обобщающее значение books.

Опора на уроке: произнести реплику → определить ситуацию или референт → выбрать форму → проверить, сохранился ли смысл. Формулировки находятся в EngPrimary и EngSec.
