# Русский язык. 1–4 классы

В ответах слоги считались по числу букв. Шесть слов снабжены проверенными парами: например, «лес» — 1 слог, 3 звука; «книга» — 2 слога, 5 звуков. Для «ель» объяснено, почему при трёх буквах получаются три звука.

Для 24 слов на жи–ши, ча–ща, чу–щу составлены пары «слово с одной пропущенной буквой — полное слово». Раньше подчёркивание добавлялось перед буквой и ребёнок видел ответ. В морфемном разборе «переход» и «домик» указано нулевое окончание и проверочная форма.

Работа со словом: произнести → услышать гласные и посчитать слоги → сопоставить со звуками. На орфограмму ученик записывает пропущенную букву и сравнивает с целым словом. В задании о границах предложений даны короткий текст для чтения учителем и ключ. Материал находится в RuPrimary.
