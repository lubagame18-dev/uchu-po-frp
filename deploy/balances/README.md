# Балансы кабинета — 15 ноября 2026

До изменений: `lessonBadge`/`tokBadge` были текстовыми плашками; расход уроков
дополнялся локальными счётчиками устройства, профиль запрашивался не при каждом
входе. `spend_ai` списывал токены, но не отмечал создание целого урока.

Теперь источник балансов — PocketBase: `plan`, `ai_left`, `ai_limit`,
`tokens_limit`, `tokens_used`, `paid_until`. Балансы не сохраняются в localStorage.
Вход, открытие вкладки, завершение генерации/доработки и возврат с оплаты обновляют
профиль. Числа в плашках — реальные остатки; подписи доступны при наведении,
фокусе и через доступное имя progressbar. Неизвестные данные — «—»/«Загрузка…».
Плашки одинакового размера, без выступов и ссылки на докупку: справа от заголовка
на компьютере, рядом под заголовком на телефоне. Область задана сеткой CSS и не
сдвигается при обновлении баланса, перерисовке или движении декоративных фигур.

Новые кабинеты: `none`, 0 уроков и токенов, без пробного тарифа. Один урок — 30 ₽,
3 урока — 90 ₽. Подписки: номинальная шкала 50 уроков, токены отдельно.
Серверная отметка `quota_counted` не позволяет повторно списать один урок.
Исторические уроки не списываются заново. Миграция сохраняет оплаченные остатки
и материалы; снимает только старые неоплаченные пробные начисления.

Браузерные проверки используют настоящий изолированный PocketBase, два отдельных
контекста браузера, ширины 320/360/768/1024/1440. Скриншоты:
`work/balances-browser/header-360.png`, `header-1440.png` (не выкладываются на сайт).
Проверяются 3→2, 50→49→0, независимый расход токенов, отсутствие балансов в кэше,
загрузка/отсутствующие поля, подписи при наведении и фокусе, числа внутри плашек,
равные размеры и сохранение положения при перерисовке, списании и перетаскивании.
Платёжные сценарии — фикстуры серверного подтверждения; реальные деньги не списываются.

`update-server.py --ref <FULL_SHA>` на существующем VPS проверяет manifest,
делает зашифрованный бэкап, прогоняет миграцию на закрытой копии настоящей БД,
проверяет сохранность пользователей/материалов/оплаченных остатков, меняет код,
проверяет health и восстановление из независимого S3-бэкапа. Ключи не меняются.
Сбой установки возвращает прежние hooks; живая БД не заменяется старым снимком.
Приватная квитанция: `/root/uchu-balances-release/receipt.json`.

После проверок — push существующей `codex/pocketbase-accounts`, merge в main,
ручной `gh workflow run deploy-yandex.yml --ref main`, проверка живых SHA-256
по `release.json` и браузерного макета. При сбое статики — revert коммита этой
выкладки, повторный запуск workflow и проверка прежних файлов.
