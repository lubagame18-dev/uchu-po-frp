# Содержательная сборка уроков и реальные страницы

`js/lesson-quality.js` задаёт отдельные содержательные требования всем 24 пунктам списка предметов: русский язык, литература, математика, история, английский язык, биология, география, физика, химия, обществознание, информатика, окружающий мир, ИЗО, музыка, технология, физкультура, ОРКСЭ, ОБЖ/ОБЗР, вероятность и статистика, МХК, русский начальной школы, литературное чтение, астрономия и другой предмет.

Каждый предмет получает требования к объяснению, разобранным образцам, конкретным заданиям, проверенным ответам, типичным ошибкам и итоговой проверке. Возраст, длительность, тема, пожелания учителя, прежняя методика, обозначения и формат документа сохраняются. Объём не заполняется повторениями и темами всего года.

Без читаемых фотографий урок самодостаточен: теория, текст/исходные данные, условия, образцы и ключи находятся в комплекте. Название книги, пожелание, библиотечная заготовка или нечитаемый файл не доказывают наличия конкретной страницы. Нет отсылок к отсутствующему параграфу, упражнению, атласу или аудиозаписи. Упоминание книги как предмета (например, куда положить закладку) не считается отсылкой к источнику.

С читаемыми страницами первичны их реальные задания. Внутренний шаблон не конкурирует с ними. Используются только распознанные номера; если номера не видно — ссылка на фото без придуманного номера. Прикладная теория объясняется своими словами, добавляются аналогичные авторские задания. Длинные защищённые упражнения не размножаются. OCR сохраняет номера; неуверенное распознавание требует более чёткого снимка. Восстановление сборки и доработка сохраняют исходные вложения в контексте.

Все предметы сначала создают единую содержательную основу. Рабочий лист и презентация согласуются с ней. Конвертация старой техкарты в новый формат и конспект сохраняет объяснения, задачи и решения вне исходной таблицы. Если генерация не дала документа или осталась ссылка на отсутствующий материал, сохраняется отмеченный черновик, а не безусловное сообщение об успехе.

Проверка реальной моделью обнаружила расход всего лимита на скрытое рассуждение с пустым `content`. Платные запросы сайта теперь используют проверенный `thinking: {type: "disabled"}` и температуру 0,25. Фиксированная модель, атомарные бюджеты создания/доработок, стоимость урока и оплаченные остатки сохранены. Протокол подтверждён официальной документацией: https://api-docs.deepseek.com/guides/thinking_mode и https://api-docs.deepseek.com/api/create-chat-completion .

Также исправлены неверные универсальные признаки жанров в `js/litprimary.js`: рассказ может быть о вымышленных событиях; басня не обязательно о животных и не обязательно с моралью в конце; рифма не обязательна для любого стихотворения/загадки; не всякая сказка волшебная. Существующие произведения и тексты базы знаний не переписывались.

Локально:

```bash
node deploy/lesson-quality/test-prompts.cjs
LESSON_RULES_JSON=<закрытый JSON сохранённых правил, необязательно> node deploy/lesson-quality/test-browser.cjs
python3 deploy/pocketbase/test-integration.py
POCKETBASE_BROWSER=1 PLAYWRIGHT_MODULE=/opt/codex/cua_node/lib/node_modules/playwright python3 deploy/pocketbase/test-balances.py
python3 deploy/check-site-deploy.py
```

`test-prompts.cjs` не требует дополнительных библиотек и входит в CI. Браузерная проверка использует уже установленный Playwright, настоящие функции сборки всех предметов, проверяет контекст фотографий/правок, сохранность содержания при конвертации и завершение учёта при сбое сохранения.

Опциональный прогон реальной модели использует существующий ключ из файла с правами 600. Ключ не записывается в результаты. Учебные примеры не содержат персональных данных; пользовательские оплаты/остатки для QA не создаются и не списываются. Расход ограничен расчётными единицами, результаты сохраняются для просмотра и повторно не генерируются без удаления предыдущего артефакта.

```bash
python3 deploy/lesson-quality/check-model.py --prompts work/lesson-quality/prompts.json --key-file <закрытый файл> --output work/lesson-quality/model
python3 deploy/lesson-quality/check-model.py --prompts work/lesson-quality/prompts.json --key-file <закрытый файл> --output work/lesson-quality/reviews --review-input work/lesson-quality/model --max-units 100000
LESSON_MODEL_DIR=work/lesson-quality/model LESSON_REVIEW_DIR=work/lesson-quality/reviews node deploy/lesson-quality/test-browser.cjs
```

Артефакты находятся в `work/lesson-quality/`, исключённом из публикации. Проверки включают по одному реальному образцу всех 24 предметов, дополнительные образцы с фото, редакторскую проверку и применение правок настоящей функцией `reviewConspect`. Это выборочная проверка, не доказательство безошибочности всех возможных тем. Неподтверждённые точные сведения, цитаты, свежая статистика и опасные практики не должны выдаваться за проверенные факты.

Выкладка: существующий `deploy-yandex.yml` с `accounts_only=true` явно включает изменённые JS. Полный состав и SHA-256 — `release.json`. Cloud Function обновляется существующим проверяемым инструментом с `--manifest deploy/lesson-quality/release.json`; конфигурация, секреты и провайдеры сохраняются. Новых сервисов и зависимостей нет.
