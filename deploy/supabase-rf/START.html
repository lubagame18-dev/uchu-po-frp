Порядок действий

01Вам · аккаунт и оплата

Создать VPS в РФ

Выберите российский регион, Ubuntu 24.04, ориентир 4 vCPU / 8 ГБ RAM / 80 ГБ SSD. Это рекомендуемые ресурсы, не проверенный тариф. Стоимость уточните на сайте.

Официальная страница ↗
02Вам · DNS

Добавить DNS-записи

В панели регистратора добавьте A-записи supa и studio на IP VPS. Уберите конфликтующие AAAA, если IPv6 не настроен. Проверьте оба имени.

Официальная страница ↗
03Вам · доступ

Предоставить SSH-доступ

Передайте Codex SSH-адрес и доступ через защищённые настройки среды. Не присылайте приватный ключ в чат. Если SSH не работает, отправьте сообщение ниже.

Официальная страница ↗
04Вам · решение и подпись

Подтвердить юридическую часть

С юристом подтвердите политику, согласия, поручения обработки, уведомление РКН, сроки хранения и удаления. Российский VPS сам по себе не доказывает соблюдение 152-ФЗ.

Официальная страница ↗
05Вам · доступ к аккаунту; выгрузку делает Codex

Разрешить выгрузку исходного проекта

Предоставьте доступ к базе через защищённые настройки. Codex сначала проверит версии и сделает пробный перенос. Старый проект не удалять.

Официальная страница ↗

Выберите провайдеров с подходящими условиями хранения ПД. Codex настроит SMTP/SMS после доступа. Регистрация на новом сервере по умолчанию выключена до теста доставки.
