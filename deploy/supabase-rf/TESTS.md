# Приёмочные проверки Codex после доступа к VPS

Статус всех live-проверок: НЕ ВЫПОЛНЕНЫ. В START отмечать «Да» только по артефакту.

| Проверка | Действие и ожидаемый результат |
|---|---|
| География | Документы провайдера: VPS, disks, logs, backup физически в РФ |
| DNS/TLS | A supa/studio на VPS, валидный TLS, внешние 8000/5432/6543 закрыты |
| API/Studio | health 200, supa root 404, studio без basic auth 401 |
| Старый пароль | Мигрированный тестовый пользователь входит прежним паролем, UUID тот же |
| Новый пользователь | Новый тестовый email регистрируется, получает письмо и подтверждается; повтор email обрабатывается |
| Сессия | Выход, recovery, истечение, повторный вход; после переключения старый токен не отправляется на новый API |
| SMS/OAuth | Верный/неверный/просроченный код, resend/rate limit, новый callback и подпись хука |
| Уроки/RLS | test-live.py: два тестовых владельца, CRUD, чужой lesson_id, подмена user_id запрещена |
| UI сохранение | Создать тестовый урок, сохранить, перезагрузить, открыть и отредактировать; второй браузер видит синхронизированное изменение |
| Word/PDF | Существующий тестовый урок без генерации: скачать оба формата; DOCX — ZIP с word/document.xml и прежним текстом, PDF начинается %PDF-, открывается и содержит страницы; размер >0. Повторить после перезагрузки |
| Оплата | В sandbox создать платёж, server amount, корректный профиль target UUID, два одинаковых webhook не увеличивают баланс дважды; trial/quota тоже используют target |
| Данные | Counts/fingerprints всех таблиц до/после frozen export, identities/password hashes, grants/RLS/functions, metadata и реальные Storage objects |
| Backup | Старый export и новый backup вне сайта; SHA256 верны; восстановление на отдельном тестовом VPS с теми же ключами; повтор health/вход/RLS |
| Старый проект | Не удалён, запись заблокирована, план обратной дельты и отката проверен |

Каждой проверке приложить дату, версию, команду и результат без ПД/секретов.
Playwright-проверка START не заменяет экспорт и платежный E2E рабочего приложения.
