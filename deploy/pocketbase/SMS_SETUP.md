# SMS для нового кабинета: план без подключения платных опций

08.11.2026. Владелец сообщил, что SMS-провайдера ещё нет. Для начала предлагается
SMSPILOT, общий отправитель. Аккаунт не создан, договоры не приняты, баланс не
пополнялся, ключа и проверенной реальной отправки у Codex нет.

## Почему этот вариант

Проверены официальные страницы:

- https://smspilot.ru/price_personal.php?tab=tariff — тариф частного клиента без
  абонентской платы, общее имя. Публичная таблица на дату проверки: МТС 8,58 ₽,
  Мегафон/Yota 8,35 ₽, Билайн 11,21 ₽, t2 9,00 ₽ за SMS. Остальные направления
  имеют собственные цены. Это снимок условий, не гарантия будущей цены.
- https://smspilot.ru/faq.php — физлица могут отправлять на произвольные номера
  по согласованному сервисному шаблону. Для юридического лица/ИП использовать
  соответствующую категорию; юридический статус определяет владелец.
- https://sms.ru/price — для индивидуального имени есть существенная абонплата;
  например, МТС 3 000 ₽/месяц за имя. Такой режим не соответствует бюджету старта.
- https://smsc.ru/tariffs/ — платные имена и разные условия по операторам. Не
  подтверждено, что этот вариант выгоднее общего имени на малом объёме.

Это выбор для подготовки интеграции, а не заявление, что найдена самая низкая
цена на всём рынке. До оплаты проверить кабинет, оферту, модерацию и получателя.

## Только действия владельца аккаунта

1. Открыть https://smspilot.ru/my.php?a=reg и зарегистрироваться своими контактами.
   Не создавать аккаунт на выдуманное лицо, не передавать пароль Codex в чат.
2. В https://smspilot.ru/my-settings.php?tab=api найти 64-символьный API-ключ.
   Секретное имя для защищённой конфигурации — `SMSPILOT_API_KEY`.
   В чат сообщить только факт создания аккаунта, ключ здесь не публиковать.
3. В https://smspilot.ru/my-template.php согласовать сервисный шаблон для
   одноразового кода, без покупки индивидуального имени:
   `Код входа в «Учу по ФРП»: ______` (переменная часть — шесть цифр).
   Синтаксис переменной в актуальной форме проверить при согласовании; точный
   текст реальной отправки: `Код входа в «Учу по ФРП»: 123456` с новым кодом.
4. Не подключать платное имя/пакет/автопополнение. Сначала Codex проверяет API и
   расчёт цены без отправки; реальная тестовая SMS — только после доступа,
   подтверждения получателя и расходов. Активация услуги на нужных условиях
   и принятие оферты остаются за владельцем.

Владелец выбрал один новый кабинет PocketBase. Пять своих аккаунтов в Supabase
оставляет в исходном проекте; импорт и объединение их записей не выполняются.
Сохранённые там уроки/материалы автоматически в новый кабинет не копируются.

## Что делает Codex

Адаптер подготовлен: `SMS_PROVIDER=smspilot`, `SMSPILOT_API_KEY` в env PocketBase.
`SMS_SENDER` оставить пустым, пока конкретный отправитель не подтверждён провайдером.
Ключ отправляется только POST-телом на `https://smspilot.ru/api.php`; в URL и
клиентском JS ключа нет. Подтверждение очереди не выдаётся за подтверждение доставки.
Нет автоматического переключения на другой платный сервис при ошибке.

Публичная отправка остаётся выключена: `UCHU_ALLOW_SMS=false`,
`UCHU_ALLOW_SMS_SIGNUP=false`. После размещения и приёмки включение выполняет Codex.
Дополнительно действуют антиспам-ограничения на номер, IP и сутки.

Новый месячный предел `SMS_MONTHLY_MAX=20` считает попытки отправки, включая
сбои с неизвестным статусом. Счётчик в SQLite переживает рестарт, месяц — UTC.
Это предел числа запросов, **не денежный потолок**: тарифы и абонплаты провайдера
контролируются отдельно. Перед запуском согласовать месячный предел и бюджет.
Изменение провайдера не обнуляет счётчик.

Безопасные проверки после получения защищённого доступа к серверу:

```bash
# Все команды выполняет Codex. ENV — существующий защищённый файл 600.
python3 deploy/pocketbase/check-smspilot.py --env-file <SERVER_ENV_FILE>
python3 deploy/pocketbase/check-smspilot.py --env-file <SERVER_ENV_FILE> --phone <OWNER_TEST_PHONE>
```

Первый запрос читает баланс, второй использует `cost=1` и считает стоимость
без отправки. Скрипт не содержит режима настоящей отправки, не печатает ключ,
номер, текст SMS или полный ответ провайдера. Ключ нельзя передавать аргументом CLI.
Код настоящего входа проверяется через PocketBase после приёмки интеграции.

Проверки без ключа/отправки:

```bash
node deploy/pocketbase/test-identity-providers.cjs
python3 deploy/pocketbase/test-sms-setup.py
python3 deploy/pocketbase/test-identities.py
```

Все сетевые действия провайдера в этих тестах имитируются. Настоящий аккаунт,
модерация шаблона, баланс и доставка пока не проверены.
