Где нажать: DNS в Яндексе

  1. Сначала Codex должен получить доступ к серверу, установить PocketBase и сообщить его публичный IP. До этого DNS менять не нужно.
  2. В консоли Яндекса откройте Cloud DNS → зону вашего домена. Проверьте, что её NS совпадают с авторитетными NS у регистратора; иначе записи меняются у другого DNS-провайдера.
  3. Добавьте только запись A для accounts.<ваш домен>. с IP нового сервера. Существующие записи сайта и почты сохраняйте.
  4. Отправьте Codex имя поддомена и статус записи. IP и доменное имя можно прислать в чат; пароли и ключи передавайте через защищённые настройки доступа.

Если сомневаетесь, скопируйте сообщение о DNS в поддержку. Проверку DNS и HTTPS выполнит Codex после доступа.
