01

Создайте и оплатите VPS SpaceWeb

Тарифы VPS ↗Ваша панель и оплата ↗
  1. Откройте свою панель SpaceWeb. Нужна услуга VPS/VDS, а не домен или обычный хостинг. Найдите создание VPS; названия разделов могут отличаться.
  2. Выбранные параметры: 1 ядро, 1 ГБ RAM, 10 ГБ NVMe, обычный IPv4, Ubuntu amd64, без дополнительного ПО. Платная панель ispmanager для PocketBase не нужна. Выбранная Ubuntu 26.04 LTS поддерживается установщиком, если доступна у провайдера.
  3. Вы разрешили до 520 ₽/месяц вместе с обычным IP и тремя бэкапами. По показанным параметрам расчёт за 31 день около 518,63 ₽. Перед оплатой проверьте итог в своей панели; при иной цене сообщите её. SMS не заказывайте.
  4. Создайте заказ и пополните баланс или сформируйте счёт в своей панели. Оплачивайте только по реквизитам сформированного заказа. Codex не получил действующий счёт: единственная попытка API-авторизации вернула -32400, токен не выдан.
  5. Переданный в чат пароль смените в панели SpaceWeb. Новый пароль сюда не присылайте.
Что отправить мне в чат
  • Сервер создан: да/нет; публичный IPv4; выбранная ОС; итоговая месячная стоимость с IP и бэкапами.
  • Номер заказа можно сообщить без платёжных реквизитов и персональных данных.

03

Создайте вход через Google

Google: OAuth-клиенты ↗Google: учётные данные ↗
  1. Войдите в свой Google-аккаунт. Выберите существующий проект для сайта или создайте проект с названием «Учу по ФРП». Покупать SMS, VPS или включать платёжные API для этого шага не нужно.
  2. Откройте Google Auth Platform. Если показана настройка приложения: заполните Branding (название, контактная почта), Audience (внешние пользователи для открытого сайта) и контакты разработчика. Подтверждение условий выполняете вы.
  3. В разделе Clients нажмите Create client. Тип — Web application, название — «Учу по ФРП». В Authorized JavaScript origins добавьте https://uchu-po-frp.ru; в Authorized redirect URIs вставьте точный адрес ниже.
  4. Создайте клиент. Скопируйте Client ID — это публичный идентификатор. Client Secret сохраняется только в защищённых настройках сервера. Файл JSON с секретом в чат не присылайте.
  5. Если приложение в режиме Testing, добавьте свою почту в Test users раздела Audience. Перед открытым запуском Codex проверит ограничения режима, а публикацию и подтверждение домена в вашем аккаунте выполните вы.
Что отправить мне в чат
  • Google Client ID (не Client Secret); callback сохранён: да/нет; режим Testing или In production.

Подключите сервер и DNS Яндекса

SpaceWeb: сервер ↗Яндекс Облако: DNS ↗DNS-проверка ↗
  1. Когда VPS создан, откройте его карточку. Найдите публичный IPv4 и способы входа: SSH-ключ, пароль или веб-консоль. Сообщите IP и тип доступа, без секретов.
  2. Если доступ можно подключить к среде Codex, Codex выполнит установку сам. Если доступна только ваша веб-консоль, на следующем шаге подготовлена одна команда для вставки в неё.
  3. Ваш домен делегирован на ns1.yandexcloud.net / ns2.yandexcloud.net. DNS меняется в Яндекс Облако → Cloud DNS → зона uchu-po-frp.ru → записи. Надпись SpaceWeb о невозможности изменить DNS при такой делегации нормальна.
  4. После проверки IP добавляется только A-запись accounts со значением IPv4 нового VPS. Если поле требует полное имя, accounts.uchu-po-frp.ru. Не меняйте NS, корневой A, www, MX, SPF и другие записи. Не копируйте старые GitHub A-записи из панели регистратора.
  5. Codex проверит DNS и HTTPS после установки. API SpaceWeb не может изменить действующую зону Яндекса.
Что отправить мне в чат
  • Публичный IP VPS; доступный способ SSH/веб-консоли; A accounts добавлена: да/нет. Секреты — только через защищённое подключение.
07

Автоустановка и проверка кабинета

install.sh в GitHub ↗Технический план ↗
  1. Если SSH подключён к Codex, этот шаг выполняет Codex. Иначе откройте терминал / веб-консоль именно нового Ubuntu VPS в панели SpaceWeb, скопируйте команду ниже, вставьте и нажмите Enter. На домашнем Windows её запускать не нужно.
  2. Команда устанавливает Python/pip/requests, PocketBase 0.40.6, хук регистрации и Systemd с автозапуском. Скачивает только файлы кабинета из закреплённого коммита. Существующую установку и базу не перезаписывает.
  3. В конце возможен запрос SpaceWeb login и скрытого password. Это необязательная проверка API; пустой login пропускает её. Пароль вводится в терминале и не сохраняется скриптом. Не вставляйте пароль в команду или эту страницу.
  4. Ожидаемый итог установки: PocketBase local health OK. Это проверка локального сервиса на сервере. Публичный кабинет ещё требует HTTPS, SMTP и секретов OAuth. Регистрация и SMS изначально выключены.
  5. Codex настроит оставшееся после доступа: HTTPS, резервные копии, почту, Яндекс и Google. Затем проверит реальные входы, привязку, изоляцию, уроки, Word/PDF, AI-прокси и тариф/разовую оплату. Автопродление подписок ещё требует отдельной проверки.
  6. Рабочий сайт пока не переключён. Локальные OAuth-проверки используют имитацию провайдеров; факт размещения и реальные оплаты не подтверждены.
Что отправить мне в чат
  • Установка запущена: да/нет; появилась ли строка local health OK. При ошибке пришлите её короткий текст, предварительно убрав секреты.
