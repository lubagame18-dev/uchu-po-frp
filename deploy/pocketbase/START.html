Шаг за шагом

01

Найдите приложение Яндекс ID

Открыть Яндекс OAuth ↗Официальная инструкция Яндекса ↗
  1. Войдите тем Яндекс-аккаунтом, которым настраивали кнопку входа на сайте. Откройте список своих приложений.
  2. Выберите приложение «Учу по ФРП» или то, в котором указан сайт uchu-po-frp.ru. Если оно уже есть, новое создавать не нужно.
  3. На странице приложения найдите ClientID (идентификатор клиента) и скопируйте его кнопкой рядом с полем. Это публичный идентификатор.
  4. Найдите Redirect URI / Callback URL. Проверьте наличие адреса ниже. Если адрес уже совпадает, менять его не нужно.
  5. Если приложений нет, сначала сообщите об этом Codex. Если понадобится регистрация, нужен тип «Для авторизации пользователей», а не «Для доступа к API».
Что отправить мне в чат
  • Название приложения и значение ClientID.
  • Совпадает ли Redirect URI с адресом ниже: да / нет. Client Secret не присылайте.
02

Посмотрите, что уже подключено для SMS

Открыть Яндекс Облако ↗
  1. В уже показанном вами каталоге нажмите карточку Cloud Functions → функцию uchu-po-frp.
  2. Откройте редактор/настройки версии функции и найдите раздел «Переменные окружения». Название вкладки может отличаться; ищите именно список переменных.
  3. Смотрите только названия: SMS_PROVIDER, SMS_API_ID, SMS_LOGIN, SMS_PASSWORD, SMS_SENDER, YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET. Значения секретов не раскрывайте и не фотографируйте.
  4. Только у SMS_PROVIDER посмотрите значение: smsru или smsc. Оно определяет, какую из двух ссылок открыть на следующем шаге.
  5. Пока ничего не удаляйте, не меняйте и не создавайте новую версию функции.
Что отправить мне в чат
  • Значение SMS_PROVIDER, если оно есть.
  • Какие из перечисленных названий переменных присутствуют. Достаточно названий, без значений.
03

Откройте кабинет вашего SMS-сервиса

Если smsru: открыть SMS.RU ↗Если smsc: открыть СМСЦ ↗
  1. Откройте только сервис из предыдущего шага и войдите в личный кабинет. Если провайдер не подключён, сообщите это Codex — создавать два аккаунта не нужно.
  2. Посмотрите баланс и статус доступа к API. На SMS.RU найдите раздел API/API_ID, на СМСЦ — настройки API и отправителя. Секретные значения оставьте в кабинете.
  3. Посмотрите, настроен ли отправитель и доступен ли тестовый режим. Если требуется платное согласование имени отправителя, пока не оплачивайте его.
  4. После доступа Codex перенесёт настройки на сервер PocketBase и проверит отправку. Ограничение расходов будет включено на сервере; сами коды в чате не нужны.
Что отправить мне в чат
  • Название сервиса; подключён ли API: да / нет.
  • Отправитель настроен: да / нет; требуется ли оплата. Сам API_ID, логин и пароль не присылайте.
04

Проверьте доступ к исходному Supabase

Открыть проект сайта ↗Открыть список проектов ↗
  1. Откройте проект по первой кнопке. Если появится запрос входа, войдите аккаунтом, который подключал базу к сайту.
  2. Если проект не найден или нет доступа, переключите организацию/аккаунт в панели. Нужный идентификатор проекта указан ниже; не создавайте вместо него пустой новый проект.
  3. Если проект открылся, посмотрите Authentication → Users и сообщите только количество пользователей. Список адресов и телефонов не копируйте.
  4. Не удаляйте проект, не меняйте RLS, пароли и ключи. Экспорт и проверку данных выполнит Codex после правильного доступа через подключение Supabase.
Что отправить мне в чат
  • Проект открылся: да / нет.
  • Только количество пользователей, если оно видно. Если доступ закрыт — текст ошибки без секретов.
05

Выберите место для PocketBase — только сервер кабинетов

Beget: VPS ↗Timeweb: VPS ↗REG.RU ↗Selectel ↗Cloud.ru ↗Яндекс Compute Cloud ↗
  1. Скачанный PocketBase — программа сервера. Отдельный аккаунт на pocketbase.io создавать не требуется. Файл на вашем компьютере ещё не означает круглосуточно работающий кабинет.
  2. Откройте официальный сайт выбранного провайдера → VPS/VDS/виртуальные серверы. Нужен Linux-сервер в РФ с постоянным диском; обычный хостинг PHP и бакет со статикой не подходят для запуска процесса PocketBase.
  3. Посмотрите полную цену: сервер, диск, публичный IP, резервные копии и возможный трафик за 31 день. Бюджет — до 500 ₽ за месяц. Цены уточните на сайте.
  4. До оплаты скопируйте публичную ссылку на подходящий тариф и отправьте Codex: я проверю параметры. Если полная цена выше бюджета или непонятна, не оплачивайте.
  5. После проверки вы создаёте и оплачиваете только этот ресурс. Основной сайт повторно покупать или переносить не нужно.
Что отправить мне в чат
  • Публичную ссылку на тариф; название провайдера.
  • Показанные CPU, RAM, диск, регион и полную месячную стоимость. Секреты и реквизиты карты не нужны.
06

После создания сервера — доступ и адрес

Открыть Яндекс DNS ↗Проверить DNS ↗Открыть документы по ПДн ↗
  1. В панели выбранного провайдера откройте созданный сервер → «Сеть» или «Публичный IP». Скопируйте публичный IPv4 и сообщите Codex; приватный адрес вида 10.x.x.x не подходит для внешнего SSH.
  2. Сообщите, какой способ SSH-доступа предлагает панель: ключ, пароль или веб-консоль. Пароль и приватный ключ в чат не отправляйте. После этого Codex подготовит безопасный способ подключения; пока не меняйте правила доступа наугад.
  3. Codex сам установит PocketBase и проверит сервер. До этого DNS менять не нужно.
  4. Когда Codex сообщит проверенный IP, откройте Cloud DNS → зону uchu-po-frp.ru. Если DNS обслуживается у регистратора, запись добавляется там. Добавьте только A-запись accounts с выданным IP. Записи основного сайта и почты сохраняйте.
  5. Почтовый сервис для подтверждения и восстановления тоже настроит Codex после доступа. Если нужно оплатить услугу или подписать документы по обработке данных, это остаётся у владельца.
Что отправить мне в чат
  • Публичный IP сервера; имя провайдера и тип SSH-доступа.
  • После настройки — поддомен accounts.uchu-po-frp.ru и статус DNS. Пароли, ключи и документы с персональными данными в чат не отправляйте.
07

Посмотреть технический план ↗Посмотреть отчёт проверок ↗

Что отправить мне в чат
