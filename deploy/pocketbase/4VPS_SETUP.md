# Только PocketBase — на 4VPS

План варианта 4VPS. После него владелец также запросил RUVDS и VDSina;
сравнение и актуальный статус выбора — HOSTING_OPTIONS.md. Меняется место первого развёртывания кабинетов;
настоящая установка PocketBase в SpaceWeb не выполнялась.

| Ресурс | Место |
| --- | --- |
| Новый PocketBase, база SQLite, файлы кабинета | Один VPS 4VPS в РФ |
| Домен и существующая почта | SpaceWeb |
| Статика сайта и существующий деплой GitHub | Яндекс Облако |
| Cloud DNS, текущая делегация NS | Яндекс Облако |

| Пять старых аккаунтов | Supabase, пока без импорта |

## Ссылки и выбор

- [Тарифы / выбор страны](https://4vps.su/).
- [Регистрация и вход](https://4vps.su/account/login): «Создать аккаунт» при необходимости.
- [База знаний](https://4vps.su/page/wiki); поддержка help@4vps.su, адрес указан на сайте.

Выбирать Россию, Ubuntu amd64, от 1 CPU / 1 ГБ RAM / 10 ГБ диска, публичный IPv4,
без платной панели управления. Покупать только после проверки итоговой цены,
периода, доступности, IPv4 и стоимости/места резервных копий. Новая почта,
перенос домена и смена NS не нужны. Условия 4VPS не наследуются от SpaceWeb.

## Установка

Одна актуальная команда находится в README.md и опубликованном START-пульте.
`install.sh` скачивает только комплект PocketBase с закреплённого коммита,
не обращается к API SpaceWeb и не запрашивает его учётные данные.
ОС/процесс/Systemd и локальный health ещё требуют проверки на настоящем VPS.
Сейчас VPS и SSH-доступ не предоставлены.

Порядок: согласовать реальный бюджет → создать/оплатить VPS → подключить SSH
→ установка → accounts A-запись в Яндексе → HTTPS/SMTP/Google/Яндекс ID
→ восстановление бэкапа и приёмка → переключение кабинета.

Адрес сервера, ОС и тип SSH-доступа можно сообщить в чат; пароли/приватные ключи —
только через защищённые настройки среды. Код и доступные технические настройки
выполняет Codex после подключения. Если доступна только веб-консоль владельца,
в пульте есть одна команда для вставки именно в терминал VPS.
