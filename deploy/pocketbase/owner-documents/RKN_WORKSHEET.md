# Рабочие сведения для уведомления Роскомнадзора

Не подано. Не подписано. Состояние от 10.11.2026.
Форма и применимые обязанности проверяются на https://pd.rkn.gov.ru/.
Прямую форму https://pd.rkn.gov.ru/operators-registry/notification/ из среды
проверки получить не удалось (таймаут); актуальный путь открыть через главную.

Для регистрации кабинетов с автоматизированной обработкой нужно проверить обязанность
уведомить Роскомнадзор до начала обработки и наличие применимых исключений.
Новый пустой кабинет сам по себе не освобождает оператора от требований.
Если сервис уже обрабатывал данные, указывать фактические даты/обстоятельства,
не объявлять всё «ещё не началось» только из-за смены базы.

Поля, которые заполнит/подтвердит владелец:

- Оператор: <ФИО>, статус самозанятой НПД, <ИНН>, <адрес>, <контактная почта/телефон>.
- Фактическая дата начала обработки, правовые основания, цели и категории субъектов.
- Обрабатываемые категории данных: email, аккаунт/идентичности входа, содержание
  личного кабинета, платежи/лимиты, техжурналы в фактически проверенном составе.
- Адреса баз/ЦОД и лица, обрабатывающие данные по поручению. Для JustHost нужно
  получить точное юридическое лицо/адрес ЦОД из договора или у поддержки: один
  город «Новосибирск» и имя бренда для всех полей недостаточны.
- Меры защиты, ответственное лицо, прекращение обработки и сроки — по факту,
  а не выбор всех мер из формы без их внедрения.
- Старый Supabase: данные не импортируются, но старый проект пока содержит записи.
  Указать его судьбу и применимые обязанности отдельно, не скрывать существование.
- Google и фактические иностранные AI-провайдеры: оценить трансграничные потоки,
  получателей/страны и необходимость отдельного уведомления по ст. 12 152-ФЗ.
  Обычное уведомление оператора не заменяет такую оценку и отдельную процедуру.
- Школьные quiz: проверить, поступают ли идентифицирующие данные детей; до определения
  правового режима не утверждать «сервис обрабатывает только данные взрослых».

Codex готовит техническую карту и проект ответов. Подписывает и подаёт оператор
через доступный ему официальный способ. Кнопка «подтвердить документы» в пульте
не отправляет заявление и не подтверждает регистрацию в реестре.
