# Распознавание таблиц из PDF

Скрипт `ocr_pdf.py` вытаскивает таблицы из сканированных PDF:
- PyMuPDF находит линии таблиц и координаты ячеек;
- Tesseract OCR распознаёт русский текст;
- слова раскладываются по ячейкам и сохраняются в JSON.

## Что нужно

1. Python с `pymupdf`.
2. Tesseract OCR 5 с русским языком:
   - установить Tesseract;
   - скачать `rus.traineddata` из tessdata_fast;
   - положить в папку без кириллицы в пути, например `C:\tessdata_uchu`.
3. Запуск:

```bash
python tools/pdf-tables/ocr_pdf.py "книга.pdf" \
  --subject math --title "Математика" \
  --tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe" \
  --tessdata "C:\tessdata_uchu" \
  -o tools/pdf-tables/math.json
```

Для нескольких книг можно передать несколько PDF сразу.

## Важное ограничение

Это сканы школьных справочников. OCR читает **текст**, но:
- формулы, дроби и индексы часто распознаются с ошибками;
- объединённые ячейки могут склеиваться;
- заголовки таблиц могут попасть в соседнюю строку.

Поэтому результат **не подключается к урокам автоматически**: сначала таблицу нужно
проверить глазами. Скрипт нужен, чтобы быстро получить черновик таблиц и потом
отредактировать их вручную.

Для гарантии «в каждой теме есть таблица» в программе используется банк схем
`js/schemes.js` и `TableKit` (`js/tablekit.js`): готовые таблицы + конструктор.
