Сборка теста

Конструктор интерактивной HTML-страницы теста. Ученик проходит её с телефона, результаты приходят в личный кабинет → «Результаты тестов».

Формат: {"questions":[{"q":"текст вопроса","options":["А","Б","В"],"answer":1,"explain":"пояснение"}]}. Можно вставить JSON, собранный DeepSeek по кнопке ниже.
