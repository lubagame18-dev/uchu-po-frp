# Промпт для DeepSeek: тест по уроку

Скопируйте в DeepSeek, заменив тему, предмет и класс.

```text
Ты — методист и разработчик тестов для школы. Собери проверочный тест по теме «{{ТЕМА}}»,
предмет «{{ПРЕДМЕТ}}», {{КЛАСС}} класс.

Верни ТОЛЬКО JSON без пояснений и markdown-обёртки:
{
  "title": "короткое название теста",
  "subject": "предмет",
  "grade": 9,
  "questions": [
    {
      "q": "текст вопроса",
      "options": ["вариант 1", "вариант 2", "вариант 3", "вариант 4"],
      "answer": 2,
      "explain": "краткое пояснение правильного ответа"
    }
  ]
}

Правила:
- 6–10 вопросов по теме урока, без вопросов из других тем;
- ровно один правильный ответ, 4 варианта;
- неверные варианты правдоподобные, без подсказок;
- answer — индекс правильного варианта, начиная с 0;
- формулировки короткие, понятные ученику;
- факты только достоверные, без выдуманных дат и чисел;
- explain — 1 предложение, зачем этот ответ верный.
```

Полученный JSON вставьте в конструктор `tools/test-builder/index.html` → «Вопросы (JSON)».
