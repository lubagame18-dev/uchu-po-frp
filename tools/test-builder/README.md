# Конструктор тестов

Инструмент для сборки интерактивной HTML-страницы теста. Результаты учеников попадают в
личный кабинет учителя → «Результаты тестов» (таблицы `quizzes` и `quiz_results`, SQL — `supabase_quizzes.sql`).

## Как пользоваться

1. Откройте на сайте: `https://uchu-po-frp.ru/tools/test-builder/index.html` (нужно быть в личном кабинете).
2. Впишите название, предмет и класс.
3. Нажмите **«Скопировать промпт для DeepSeek»**, вставьте промпт в DeepSeek и получите JSON.
4. Вставьте JSON в поле «Вопросы (JSON)».
5. Нажмите **«Создать тест в кабинете»** — создаётся запись теста, её код появится в поле «Код теста».
6. Нажмите **«Собрать страницу»**, затем **«Скачать HTML»** (или «Открыть в новой вкладке»).
7. Выложите HTML на сайт или раздайте ученикам; после прохождения результат придёт в кабинет.

## Формат JSON

```json
{
  "title": "Название теста",
  "subject": "География",
  "grade": 9,
  "questions": [
    { "q": "Вопрос?", "options": ["А", "Б", "В", "Г"], "answer": 2, "explain": "Почему это верно" }
  ]
}
```

`answer` — индекс правильного варианта, начиная с 0.
