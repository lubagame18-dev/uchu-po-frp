# Личный кабинет, ИИ сайта, тарифы и оплата

Что уже сделано в коде и что нужно включить вам. Всё по шагам.

---

## 1. Личный кабинет (вход по почте, уроки в облаке)

Уроки сохраняются в облаке и не пропадают при очистке браузера. Вход — почта и пароль от 6 знаков, без требований к символам. Вход запоминается на устройстве.

Облако — бесплатный проект **Supabase** (supabase.com).

1. Зарегистрируйтесь на supabase.com → **New project** (регион — Frankfurt).
2. **Authentication → Sign In / Providers → Email**: выключите «Confirm email» (тогда не нужно подтверждать почту по письму). Минимальную длину пароля оставьте 6.
3. **SQL Editor → New query** → вставьте и выполните:

```sql
-- уроки: каждый видит и меняет только свои
create table if not exists lessons (
  id text primary key,
  user_id uuid not null default auth.uid() references auth.users on delete cascade,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table lessons enable row level security;
create policy "свои уроки" on lessons for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

-- тариф и остаток запросов к ИИ (меняет только сервер)
create table if not exists profiles (
  id uuid primary key references auth.users on delete cascade,
  plan text not null default 'free',
  ai_left int not null default 15,
  paid_until timestamptz,
  free_month text
);
alter table profiles enable row level security;
create policy "свой профиль — только чтение" on profiles for select using (auth.uid() = id);
```

4. **Project Settings → API**: скопируйте **Project URL** и ключ **anon public**.
5. В `index.html`, в блоке `window.UCHU_SITE` вверху, заполните:
   `cloud: { url: "https://….supabase.co", anonKey: "eyJ…" }`.
   Ключ anon — публичный, его можно хранить в коде сайта. Секретный ключ **service_role** — только в Яндекс-функции (шаг 2.3), никогда в сайте.

После этого вверху сайта кнопка «👤 Войти» начнёт работать.

## 2. ИИ сайта: ключи DeepSeek только на сервере

Учитель не видит ключей и не знает о них: сайт обращается к вашей Яндекс-функции, функция — к DeepSeek.

1. **Код функции.** Загрузите в функцию файлы из папки `proxy/`: `proxy.js`, `yandex-function.js`, `deepseek-pool.js`, `quota.js`. Точка входа — `yandex-function.handler`.
2. **Аккаунты DeepSeek.** В настройках функции добавьте переменную `DEEPSEEK_POOL`:
   `[{"email":"почта-1","key":"sk-…","isActive":true},{"email":"почта-2","key":"...","isActive":true}]`
   - Запросы идут по кругу. Если у аккаунта кончились деньги (ошибка 402) или сработал лимит (429), запрос сам повторяется на следующем, учитель ошибки не видит.
   - Ключ `"..."` — заглушка: такой аккаунт пропускается, пока вы не вставите настоящий ключ.
   - `"isActive": false` — аккаунт выключен вручную.

   Достаточно и одного аккаунта: у DeepSeek высокий предел одновременных запросов (2500).
3. **Учёт тарифа.** Добавьте переменные `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` (ключ service_role) и, по желанию, `FREE_AI` — сколько бесплатных запросов в месяц (по умолчанию 15). Без входа в кабинет ИИ сайта не работает, после лимита функция вежливо отказывает.
4. **Баланс аккаунтов.** Задайте переменную `ADMIN_TOKEN` (любое слово). Тогда адрес `…?path=/deepseek/balance` с заголовком `X-Admin-Token` показывает баланс каждого аккаунта.
5. **Включение на сайте.** В `index.html` поставьте `siteAi: true`. В «⚙ ИИ» первым в очереди станет «ИИ сайта».

## 3. Сколько стоит ИИ и какие тарифы ставить

**Цены DeepSeek** (официальная страница, октябрь 2026; модель `deepseek-flash`, за 1 млн токенов):

| | днём (пик) | вне пика |
|---|---|---|
| ввод | $0,30 | $0,15 |
| вывод | $1,20 | $0,60 |

Пик — 01:00–04:00 и 06:00–10:00 UTC по будням, то есть 06:00–09:00 и 11:00–15:00 по Екатеринбургу. Это школьное время, поэтому считаю по пиковой цене.

Старые имена моделей `deepseek-chat` и `deepseek-reasoner` отключены 24.07.2026. Сайт теперь сам использует `deepseek-flash`.

**Один урок с ИИ** (техкарта, презентация, рабочий лист): около 25 тыс. токенов на вход и 14 тыс. на выход.
- Цена: 25 000 × 0,30 / 10⁶ + 14 000 × 1,20 / 10⁶ ≈ $0,024. При курсе 90 ₽ это примерно 2,2 ₽.
- С запасом на комиссии при оплате из России берём **≈ 3 ₽ за урок**. Правка листа — около 1 ₽.

**Что остаётся с подписки:** комиссия платёжного сервиса около 3,8% и налог самозанятой 4%. С 500 ₽ остаётся около 460 ₽.

| Тариф | Цена | Что входит | Расход на ИИ (макс.) | Остаётся вам |
|---|---|---|---|---|
| Бесплатный | 0 ₽ | без ИИ — всё; ИИ сайта — 15 запросов в месяц или свой бесплатный ИИ (OpenRouter) | ≈ 45 ₽ на человека | — |
| «Учитель» | 300 ₽/мес | без ИИ, облако, все листы и скачивание | 0 ₽ | ≈ 275 ₽ |
| «Учитель + ИИ» | 500 ₽/мес | + 50 уроков с ИИ (или 150 правок) | ≈ 150 ₽ | ≈ 310 ₽ |
| «Методист» | 900 ₽/мес | + 120 уроков с ИИ | ≈ 360 ₽ | ≈ 470 ₽ |

В кабинете показывается, сколько запросов к ИИ осталось.

## 3а. Промокод — скидка 50% и своя нейросеть

- **Обычные пользователи** платят полную цену; ИИ — только «ИИ сайта» по тарифу.
- **По промокоду** (сначала вход в кабинет, потом код в окне тарифов) все тарифы стоят вдвое дешевле: «Учитель» — 150 ₽, «Учитель + ИИ» — 250 ₽, «Методист» — 450 ₽. Без оплаты — бесплатный тариф (3 урока в месяц).
- В тарифах с ИИ по промокоду работает **своя нейросеть** человека: при оформлении сайт просит подключить ключ (кнопка «Подключить ключ», простое окно на одну нейросеть), без ключа оплата не открывается. ИИ сайта такой пользователь не расходует; докупать уроки с ИИ и автоплатёж ему не нужны.
- Скидку считает сервер (колонка `promo` в `profiles`), поэтому подделать цену на странице нельзя.
- **Разработчик** (вход по паролю: внизу страницы или внизу окна кабинета) — всё бесплатно и без ограничений: любые свои нейросети, ключи ИИ сайта, материалы учителей.

## 4. Приём оплаты (вы — самозанятая)

**Сервисы:** Робокасса (для самозанятых — «Робочеки»: чек в «Мой налог» формируется сам) или Продамус (есть подписки; комиссия 3,8%, рекуррентные платежи подключаются отдельно). Оба присылают уведомление об оплате на ваш сервер (webhook).

**Как это работает:**
1. Учитель нажимает «Оплатить тариф». Функция создаёт платёж: сумму и номер подписывает секретом магазина, который хранится только на сервере.
2. Учитель платит картой Мир или по СБП на странице сервиса.
3. Сервис присылает webhook на адрес функции (Робокасса — «Result URL», Продамус — уведомление о платеже). Функция проверяет подпись и сразу обновляет строку в `profiles`: `plan`, `ai_left`, `paid_until = сейчас + 1 месяц`. Тариф включается мгновенно, чек уходит на почту автоматически.
4. Деньги сервис сам переводит на вашу карту.

Этот обработчик подключу, когда вы выберете сервис и получите данные магазина (идентификатор и пароли). Нужно только место для этих данных в настройках функции.

**Пополнение DeepSeek.** Деньги на баланс DeepSeek переводите сами, раз в месяц. Функция умеет показывать баланс (шаг 2.4); можно добавить напоминание на почту или в Telegram, когда баланс ниже порога. Когда появится казахстанская карта, вы просто пополняете с неё — в сайт её вставлять не нужно.

**Чего я не делаю — автоматической цепочки «рубли → карта Казахстана → скрипт пополняет кабинет DeepSeek»:**
- скрипт, который входит в кабинет DeepSeek и платит картой, нарушает правила сервиса;
- для него данные карты пришлось бы хранить на сервере;
- регулярные переводы за рубеж для оплаты сервиса — вопрос валютного контроля и налогов, это лучше обсудить с бухгалтером.

**Проще без зарубежной цепочки:** GigaChat API (Сбер) или YandexGPT оплачиваются в рублях с российской карты, и пополнение у них автоматическое. Сайт уже умеет работать с GigaChat через ту же функцию.

## 5. Защита от копирования

- В страницу добавлены пометки `noai, noimageai`.
- Добавлен `robots.txt`, запрещающий сборщиков данных для нейросетей (GPTBot, ClaudeBot, CCBot, Google-Extended, Bytespider, PerplexityBot и др.). Он действует только в корне домена: для адреса `…github.io/uchu-po-frp/` его нужно положить в репозиторий `lubagame18-dev.github.io`, либо подключить свой домен.
- **Главное:** репозиторий сейчас публичный, поэтому код и встроенная база доступны всем. Закрыть их можно одним из двух способов:
  - сделать репозиторий приватным (публикация GitHub Pages из приватного репозитория — на платном тарифе GitHub);
  - перенести сайт на Netlify или Cloudflare Pages: они бесплатно публикуют сайт из приватного репозитория.
- Полностью защитить сайт, который работает в браузере, невозможно: всё, что видит пользователь, можно сохранить. Настоящая защита — держать методику (базу, правила подбора) на сервере и выдавать её только после входа. Это следующий шаг, и он ляжет на ту же функцию и Supabase.
