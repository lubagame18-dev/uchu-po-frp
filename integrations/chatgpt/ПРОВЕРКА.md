# Проверка перед отправкой в ChatGPT

- [x] config_chatgpt.json — корректный JSON, 4 предмета.
- [x] tasks.json — 14 заданий, у каждого есть numbered_elements.
- [x] В пакете нет географии, литературы, истории и других запрещённых предметов.
- [x] В правилах: слова, буквы, заголовки и подписи на изображении запрещены.
- [x] Разрешены только цифры 1..N и стрелки.
- [x] Материалы скопированы без изменения текста.

## Тест
Прикрепите `chatgpt_package.zip` и `PROMPT_FOR_CHATGPT.txt`.
ChatGPT должен ответить изображением `bio-cell.png`, на котором нет слов, только цифры и стрелки.
Если он пишет подписи на картинке — остановите и повторите промпт, добавив: «На изображении запрещены любые слова и подписи. Только цифры и стрелки».
