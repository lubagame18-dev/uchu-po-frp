# ChatGPT: как подключиться и что делать

## 1. Что приложить
Прикрепите к сообщению один из вариантов:
- весь `chatgpt_package.zip`;
- или `tasks.json` + `config_chatgpt.json` + папку `materials`;
- или только `tasks.json`, если ChatGPT умеет читать JSON.

## 2. Что вставить в чат
Скопируйте текст из `PROMPT_FOR_CHATGPT.txt` и отправьте вместе с файлами.

## 3. Что должно получиться
Для каждого задания — отдельное изображение. Имена файлов = id задания:
`bio-cell.png`, `chem-atom.png`, `phys-solve.png`, `soc-rights.png`.

## 4. Чего категорически нельзя
- писать на картинке слова, буквы, заголовки, подписи;
- добавлять свои элементы;
- рисовать для географии, литературы, истории и других запрещённых предметов;
- придумывать факты: список элементов уже дан в tasks.json.

## 5. Если ChatGPT не видит JSON
Откройте `tasks.json`, скопируйте один task в сообщение и попросите нарисовать только его. Начните с `bio-cell`.
