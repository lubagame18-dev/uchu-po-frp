# ChatGPT: старт

Пакет для ChatGPT Plus: **3006 уроков ФРП**, **5847 изображений** по 8 предметам:
математика, биология, русский, физика, химия, обществознание, информатика, ОБЖ.

## Как работать
1. Приложите к чату образец стиля (вашу картинку).
2. Приложите **один** файл предмета из `frp_tasks/`, например `bio.json`.
3. Скопируйте `PROMPT_FOR_CHATGPT.txt`.
4. ChatGPT создаёт все изображения урока по порядку `order`.

## Имена файлов
`<lesson_id>-<order>.png`, например `bio-5-001-1.png`, `bio-5-001-2.png`.

## Категорически нельзя
- писать на картинке слова, буквы, заголовки, подписи;
- добавлять свои элементы;
- рисовать другие предметы;
- придумывать факты: списки элементов уже в JSON.

Расшифровку цифр печатает сайт, не ChatGPT.
