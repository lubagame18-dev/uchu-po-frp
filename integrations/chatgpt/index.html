ChatGPT: генерация схем-запоминалок

Пакет для ChatGPT Plus: биология, химия, физика, обществознание. Только изображения без слов и подписей; цифры-ключи и стрелки.

Файлы
  • chatgpt_package.zip — прикрепить к чату (если доступен)
  • tasks.json — точные задания и списки элементов
  • config_chatgpt.json — правила
  • START_HERE.html — инструкция
Короткий промпт

Создай по одному изображению на каждый task из tasks.json. Только 2D-вектор, пастель, белый фон. На картинке запрещены слова, буквы, заголовки и подписи. Только цифры 1..N и стрелки; цифры строго по numbered_elements. Не рисуй для других предметов. Имена файлов = id task.

Расшифровку цифр печатает сайт, не ChatGPT.
