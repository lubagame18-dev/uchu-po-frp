# Прокси для GigaChat и YandexGPT

Сайт из браузера не может обращаться к GigaChat и YandexGPT напрямую: эти сервисы не принимают запросы со страниц, а у GigaChat сертификат НУЦ Минцифры. Прокси пересылает запросы. Зависимостей нет, нужен Node.js 18+.

Сайт находит прокси сам. Учитель нажимает «Настроить автоматически», и всё. Если ключ лежит на прокси, вводить ничего не нужно ни на компьютере, ни на телефоне.

## Самый простой способ: Vercel (сайт и прокси вместе)

Если весь репозиторий опубликован на Vercel, прокси работает по адресу `https://<сайт>.vercel.app/api/ai`, и сайт находит его без настройки. Подробно — в `ИНСТРУКЦИЯ.md` в корне.

## Переменные

| Переменная | Что делает |
|---|---|
| `GIGACHAT_KEY` | ключ авторизации GigaChat. Если задан, учителям ключ не нужен |
| `YANDEX_KEY`, `YANDEX_FOLDER` | API-ключ и ID каталога Yandex Cloud, то же самое для YandexGPT |
| `ALLOW_ORIGIN` | адрес сайта, которому можно слать запросы (через запятую). Поставьте его, если ключ лежит на прокси, иначе ключом смогут пользоваться чужие сайты |
| `RATE_PER_MIN` | лимит запросов с одного IP в минуту, по умолчанию 30 |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` для физлиц (по умолчанию), `GIGACHAT_API_B2B` / `GIGACHAT_API_CORP` для организаций |
| `GIGACHAT_CA_FILE` | путь к сертификату Минцифры. Без него прокси сам скачает сертификат при первом запросе |
| `GIGACHAT_TLS_INSECURE=1` | отключить проверку сертификата Сбера, если скачать сертификат не вышло (крайний случай) |
| `PORT` | порт, по умолчанию 8787 |

Проверка: `https://<адрес-прокси>/health` отвечает `{"ok":true,"service":"uchu-po-frp-proxy",...}`. В поле `keys` видно, лежат ли ключи на сервере, в поле `cert` — нашёлся ли сертификат.

## Свой сервер (VPS)

```bash
GIGACHAT_KEY=<ключ> ALLOW_ORIGIN=https://<логин>.github.io PORT=8787 node proxy.js
```

Сайту нужен HTTPS, поэтому поставьте прокси за nginx или Caddy с сертификатом. Адрес прокси впишите в `index.html`:

```html
<script>window.UCHU_SITE = { proxies: ["https://ваш-прокси.ru"] };</script>
```

## Yandex Cloud Functions

Точка входа `yandex-function.handler`, файлы `proxy.js` и `yandex-function.js`. Функция отдаёт ответ целиком, без потока: текст появится разом, когда нейросеть закончит. Сделайте функцию публичной и впишите её адрес в `UCHU_SITE.proxies`.

## Ключ GigaChat

1. Зарегистрироваться на developers.sber.ru, создать проект GigaChat API.
2. В проекте нажать «Получить ключ», скопировать **ключ авторизации** (Authorization key).

Условия бесплатного пакета для физлиц Сбер меняет. По данным на октябрь 2026: Freemium на 12 месяцев, а с 1 сентября 2026 новых клиентов переводят на оплату через cloud.ru. Проверьте при регистрации.

## YandexGPT

Нужны API-ключ сервисного аккаунта с ролью `ai.languageModels.user` и ID каталога в Yandex Cloud. Бесплатно только в пределах стартового гранта Yandex Cloud.

## Версия 5: что нового

| Переменная / адрес | Что делает |
|---|---|
| `GIGACHAT_CA` | текст сертификата Минцифры (PEM) прямо в переменной — если нельзя положить файл |
| `russian_trusted_root_ca.pem` рядом с `proxy.js` | сертификат файлом (самый надёжный способ) |
| `PROXY_USER`, `PROXY_PASS` | логин и пароль для маршрута `/relay` (прокси — крайняя мера) |
| `RELAY_HOSTS` | куда разрешено пересылать через `/relay` (по умолчанию OpenRouter, Pollinations, DeepSeek, Gemini, Claude) |
| `YANDEX_SEARCH_KEY`, `YANDEX_SEARCH_FOLDER` | API-ключ (роль `search-api.webSearch.user`) и ID каталога для поиска картинок Яндекса |
| `GET /images?q=…` | поиск картинок через Yandex Search API (для слайдов) |
| `GET /img?url=…` | скачать найденную картинку, чтобы её можно было обрезать и вставить в PowerPoint |
| `GET /diagnose` | живая проверка: выдаёт ли Сбер токен и если нет — почему (сертификат, блокировка IP, ключ, scope, оплата) |
| `POST /relay?url=…` | пересылка запроса к зарубежной нейросети, если из сети школы она не открывается |

Если сертификат не найден ни в файле, ни в переменной и не скачался с Госуслуг, прокси включает запасной режим: для адресов Сбера проверка сертификата отключается (так же, как `verify_ssl_certs=False` в официальном SDK GigaChat). В `/health` это видно в поле `certMode`.
