# Безопасность «Учу по ФРП»: что сделать руками

Код исправлен (версия сайта 5.155, функция 23). Но часть дыр закрывается только настройками. Сделайте по порядку.

## 1. Новый код разработчика (самое важное)
Старый отпечаток кода лежал в открытом репозитории: любой мог скачать сайт и подбирать код на своём компьютере. Угадавший код получал права разработчика (чужие материалы, ключи, промокоды).
1. Придумайте **новый длинный случайный код**, 16+ символов, например из менеджера паролей.
2. На своём компьютере (нужен Node.js) посчитайте отпечаток:
   `node -e "console.log(require('crypto').createHash('sha256').update('uchu-po-frp:dev:v5'+process.argv[1]).digest('hex'))" ВАШ_КОД`
3. Яндекс Облако → функция → «Редактор» → переменные окружения: добавьте `DEV_CODE_HASH` = полученный отпечаток. Сохраните версию.
4. Вы уже в списке разработчиков (site_admins), поэтому код нужен только для новых людей. Когда всех добавите, **удалите переменную `DEV_CODE_HASH`**: вход по коду будет выключен совсем.
Без переменной вход по коду и тестовая оплата выключены. Вы входите как разработчик по почте из `site_admins`.

## 2. База (Supabase → SQL Editor)
1. Выполните `supabase.sql` (в конце появились функции атомарного списания `spend_ai` и `free_use_bump`).
2. Выполните блоками `supabase_security.sql`: проверка списка разработчиков, гашение старых промокодов, проверка бесплатного доступа, ограничения размера записей.
3. Особенно: `select * from site_admins;`. Должна остаться только ваша почта. Старая версия скрипта делала разработчиками всех зарегистрированных.
4. Новые промокоды заводите в режиме разработчика («Промокоды»). Старые считайте скомпрометированными.

## 3. Загрузить функцию v23
Яндекс Облако → функция → «Редактор» → загрузить `uchu-function.zip`. Проверка: `…?path=/health` показывает `"version":23`.
Переменные функции: `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` обязательны (без них проверка входа и тарифа выключается). Не задавайте `GIGACHAT_KEY` и `YANDEX_KEY`, если не пользуетесь: тогда эти маршруты работают только на ключах учителей.
Не обязательно: `MAX_OUTPUT_TOKENS`, `ALLOW_ORIGIN=https://uchu-po-frp.ru` (чтобы функцию нельзя было вызывать с чужих сайтов).

## 4. Supabase: настройки входа
Authentication → Providers → Email: «Confirm email» включено. Rate Limits оставьте ограниченными. URL Configuration: Site URL `https://uchu-po-frp.ru`.

## 5. Ключи
Секретные ключи (`SUPABASE_SERVICE_KEY`, ЮKassa, DeepSeek, картинки) только в переменных функции, не в репозитории. Если какой-то ключ когда-либо попадал в чат или репозиторий, перевыпустите его.
