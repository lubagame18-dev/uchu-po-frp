# Настройка по шагам: облако, сервер, оплата

Делаем по порядку. После каждого шага пишите мне, что получилось, — я проверю и подключу следующую часть на сайте.

| Шаг | Что делаем | Время |
|---|---|---|
| 1 | Облако для личного кабинета (Supabase) | 15 мин |
| 2 | Я подключаю облако к сайту, вы проверяете регистрацию | 5 мин |
| 3 | Обновляем Яндекс-функцию (сервер сайта) | 15 мин |
| 4 | Платёжный сервис (Продамус) | 1–2 дня (проверка у сервиса) |
| 5 | Тестовая оплата, включение оплаты на сайте | 15 мин |
| 6 | ИИ сайта: аккаунт DeepSeek (когда будет карта для оплаты) | 15 мин |

Что такое «секрет»: ключи с пометкой **секретный** нельзя присылать в чат и вставлять в сайт. Их вводите только в настройках Яндекс-функции. Мне можно присылать только то, что помечено «можно прислать».

## Шаг 1. Облако для личного кабинета (Supabase)

1. Откройте **https://supabase.com/dashboard** → **Sign up**. Удобнее всего войти через GitHub: у вас уже есть аккаунт `lubagame18-dev`.
2. Нажмите **New project**:
   - **Name:** `uchu-po-frp`.
   - **Database Password:** придумайте и сохраните себе. Мне не присылайте.
   - **Region:** `Central EU (Frankfurt)`.
   - Нажмите **Create new project** и подождите 1–2 минуты.
3. **Отключите подтверждение почты**, чтобы учителям не нужно было идти в почту: слева **Authentication** → **Sign In / Providers**. Переключатель **Confirm email** — на самой этой странице, вверху, в блоке **User Signups** (а не внутри «Email») → выключите → **Save changes**.
   Если переключателя нет — подтвердите уже зарегистрированную почту вручную: **SQL Editor** → `update auth.users set email_confirmed_at = now() where email = 'ваша@почта';` → **Run**.
4. **Адрес сайта:** **Authentication** → **URL Configuration** → **Site URL** = `https://lubagame18-dev.github.io/uchu-po-frp/` → **Save**.
5. **Таблицы:** слева **SQL Editor** → **New query** → вставьте весь текст ниже → **Run**. Должно появиться «Success».

```sql
-- уроки учителей: каждый видит только свои
create table if not exists lessons (
  id text primary key,
  user_id uuid not null default auth.uid() references auth.users on delete cascade,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table lessons enable row level security;
drop policy if exists "свои уроки" on lessons;
create policy "свои уроки" on lessons for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

-- тариф учителя (меняет только сервер)
create table if not exists profiles (
  id uuid primary key references auth.users on delete cascade,
  email text,
  plan text not null default 'free',
  ai_left int not null default 15,
  paid_until timestamptz,
  free_month text
);
alter table profiles add column if not exists email text;
alter table profiles enable row level security;
drop policy if exists "свой профиль — только чтение" on profiles;
create policy "свой профиль — только чтение" on profiles for select using (auth.uid() = id);

-- журнал оплат (видит только владелец в Supabase)
create table if not exists payments (
  order_id text primary key,
  user_id uuid references auth.users on delete set null,
  kind text, amount numeric, status text,
  created_at timestamptz not null default now()
);
alter table payments enable row level security;
```

6. Слева внизу **Project Settings** (шестерёнка) → **API Keys** (или **API**). Найдите три значения:

| Что | Где | Можно прислать мне? |
|---|---|---|
| **Project URL** — вида `https://abcd.supabase.co` | Project Settings → Data API (или API) | ✅ да |
| **anon / public key** — длинный, начинается с `eyJ…` или `sb_publishable_…` | API Keys | ✅ да, он публичный |
| **service_role / secret key** | API Keys | ❌ **нет, секрет** — понадобится в шаге 3 |

**Проверка, что облако открывается из России.** На телефоне, без VPN, откройте Project URL, добавив в конце `/auth/v1/health`. Должна открыться короткая строка с буквами, а не ошибка. Если не открывается — напишите мне, перенесём кабинет в Яндекс Облако.

➡️ **Пришлите мне Project URL и anon key.** Я вставлю их в сайт (шаг 2).

## Шаг 3. Обновляем Яндекс-функцию (сервер сайта)

Новый код сервера — архив **`uchu-function.zip`** в папке сайта на GitHub.

1. Откройте **https://console.yandex.cloud** → ваш каталог → **Cloud Functions** → функция с адресом `…/d4ek0q8grbhn7q5muf24`.
2. Слева **Редактор**:
   - **Среда выполнения:** Node.js 18 или новее.
   - **Способ:** **ZIP-архив** → загрузите `uchu-function.zip`.
   - **Точка входа:** `yandex-function.handler`.
   - **Таймаут:** 60 секунд. **Память:** 256 МБ.
3. Там же, в разделе **Переменные окружения**, добавьте (прежние переменные, например `GIGACHAT_KEY`, не трогайте):

| Переменная | Значение |
|---|---|
| `SUPABASE_URL` | Project URL из шага 1 |
| `SUPABASE_SERVICE_KEY` | service_role / secret key из шага 1 (**секрет**) |
| `SITE_URL` | `https://lubagame18-dev.github.io/uchu-po-frp/` |
| `ADMIN_TOKEN` | любое слово-пароль для вас (для проверки баланса ИИ) |
| `PROMO_CODES` | ваши 10 промокодов через запятую |
| `FREE_AI` | `0` — у бесплатного тарифа уроков с ИИ нет |

4. Нажмите **Сохранить изменения**. Создастся новая версия функции.
5. **Проверка:** откройте адрес функции, добавив в конце `?path=/health`. В ответе должно быть `"version":6`.

## Шаг 4. Платёжный сервис — Продамус (вы — самозанятая)

**Почему Продамус:**
- работает с самозанятыми;
- чеки сам отправляет в «Мой налог»;
- есть подписки с автоплатежом;
- код сайта уже написан под него.

**Сколько стоит** (по обзору на vc.ru):
- для новых самозанятых — бесплатный старт без автоплатежей; комиссия 3,8% с оплаты;
- автоплатежи подключаются отдельно: 1000 ₽ при подключении, 2000 ₽ позже, комиссия 3,8% с первого платежа и 4,8% с последующих.

Можно начать без автоплатежа, а включить его позже. Точные условия уточните у менеджера Продамуса при подключении.

1. Откройте **https://prodamus.ru** → **Подключиться** → выберите **«Самозанятый»**. Заполните ФИО, ИНН, телефон, почту.
2. В приложении **«Мой налог»**: **Прочее** → **Партнёры** → найдите **Продамус** → **Подключить**. Это нужно, чтобы чеки формировались сами.
3. Дождитесь, когда Продамус одобрит платёжную страницу. Её адрес будет вида `https://ваше-имя.payform.ru`.
4. В личном кабинете Продамуса, в настройках платёжной страницы, найдите:
   - **Секретный ключ** (**секрет**) → в функцию, переменная `PRODAMUS_KEY`;
   - **Адрес для уведомлений** (URL уведомлений об оплате) → впишите адрес функции + `?path=/pay/notify`, например `https://functions.yandexcloud.net/d4ek0q8grbhn7q5muf24?path=/pay/notify`.
5. В функцию добавьте `PRODAMUS_URL` = адрес вашей платёжной страницы (`https://ваше-имя.payform.ru`).
6. **Автоплатёж** (если подключили): в Продамусе создайте 3 подписки на 1 месяц:
   - «Учитель» — 300 ₽;
   - «Учитель + ИИ» — 500 ₽;
   - «Методист» — 900 ₽.

   Их номера впишите в функцию: `PRODAMUS_SUB_BASIC`, `PRODAMUS_SUB_AI`, `PRODAMUS_SUB_PRO`.

Если какого-то пункта меню не найдёте — пришлите скриншот, подскажу. Можно также попросить поддержку Продамуса: «нужна интеграция по REST API: секретный ключ и адрес уведомлений».

➡️ Напишите мне «шаг 4 готов» — я включу оплату на сайте.

## Шаг 5. Тестовая оплата

1. Я включаю на сайте оплату (и автоплатёж, если он есть).
2. Вы входите в кабинет → **тарифы** → **«Учитель»** → **«Перейти к оплате»**. Платите сами себе (минимально — можно попросить у Продамуса тестовый режим).
3. После оплаты сайт вернёт вас обратно, через несколько секунд кнопка вверху покажет «💳 Учитель».
4. В Supabase → **Table Editor** → **profiles** у вашей почты будет `plan = basic`, а в **payments** появится запись `paid`.

Если что-то не так — пришлите скриншот, разберём.

## Шаг 6. ИИ сайта — DeepSeek (когда будет карта для оплаты)

1. На **https://platform.deepseek.com** заведите столько аккаунтов, сколько хотите (например, 3). В каждом: **API Keys** → **Create new API key** → скопируйте ключ (**секрет**) → **Top up** — пополните баланс.
2. На сайте: войдите в личный кабинет своей почтой → внизу «для разработчика» → **«Ключи ИИ»**.
3. В ячейки 1, 2, 3… вставьте название (например, почту аккаунта) и ключ → **Сохранить** → **Проверить** (покажет баланс).
4. Напишите мне — я включу на сайте «ИИ сайта» для тарифов с ИИ.

Запросы учителей идут по кругу. Если аккаунт не отвечает (кончились деньги, лимит, сбой), запрос сам переходит на следующий; такой аккаунт «отдыхает» от 1 минуты до часа. Ключи хранятся в облаке в таблице `ai_keys`, которую читает только сервер; на сайте видны лишь начало и конец ключа. Пустые ячейки пропускаются, лишние можно выключить галочкой «Включён».
