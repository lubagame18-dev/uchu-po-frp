# База знаний

Здесь лежат исходные PDF, скриншоты таблиц и тексты, перенесённые из папки на ноутбуке.

- `*/Скриншоты/` — отдельные таблицы и правила, не целые страницы;
- `*/*.Таблицы...md` — тексты таблиц без изменений;
- PDF — исходные справочники.

Текст таблиц не редактируется. `knowledge/manifest.json` связывает текст и изображения.
Папка не выкладывается в Object Storage сайта из-за размера; для просмотра используйте `knowledge/index.html` в локальном/GitHub-окружении.
