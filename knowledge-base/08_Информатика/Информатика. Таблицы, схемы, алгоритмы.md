# Информатика: таблицы, схемы и алгоритмы для запоминания

Всего опор: 6. Материал сгруппирован по темам; таблицы можно использовать на уроке, в конспекте и рабочем листе.

## Алгоритм и блок-схема

| Шаг | Что делать / признак | Пример |
|---|---|---|
| 1 | овал — начало/конец, прямоугольник — действие, ромб — условие, параллелограмм — ввод/вывод |  |
| 2 | линии со стрелками: сверху вниз и слева направо |  |
| 3 | цикл: условие повторения → тело цикла → возврат |  |

## Системы счисления и единицы

| Шаг | Что делать / признак | Пример |
|---|---|---|
| 1 | основание — нижним индексом: 1011₂, 1F₁₆ | 1011₂ = 1·8 + 0·4 + 1·2 + 1·1 = 11. |
| 2 | 1 байт = 8 бит; 1 Кбайт = 1024 байта, 1 Мбайт = 1024 Кбайт |  |
| 3 | перевод: делим на основание и собираем остатки снизу вверх |  |

**Примеры:** 1011₂ = 1·8 + 0·4 + 1·2 + 1·1 = 11.

## Логические операции

| A | B | A и B | A или B | не A |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 1 |
| 0 | 1 | 0 | 1 | 1 |
| 1 | 0 | 0 | 1 | 0 |
| 1 | 1 | 1 | 1 | 0 |

## Конструкции программирования

| Конструкция | Когда нужна | Пример |
|---|---|---|
| линейная | действия по порядку | ввод → расчёт → вывод |
| ветвление | выбор из вариантов | если число > 0, то … |
| цикл for | известно число повторов | для i от 1 до 10 |
| цикл while | повторять, пока условие | пока счётчик < 10 |

## Базы данных

| Объект | Что это | Пример |
|---|---|---|
| поле | столбец таблицы | ФИО, класс |
| запись | строка таблицы | ученик Иванов, 8 А |
| ключ | уникальный идентификатор | номер ученика |
| запрос | выборка по условию | все ученики 8 А |
