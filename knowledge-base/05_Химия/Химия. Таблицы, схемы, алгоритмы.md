## Типы химических реакций

| Тип | Схема | Пример |
|---|---|---|
| соединение | A + B → AB | 2H₂ + O₂ → 2H₂O |
| разложение | AB → A + B | 2H₂O₂ → 2H₂O + O₂ |
| замещение | A + BC → AC + B | Zn + 2HCl → ZnCl₂ + H₂ |
| обмен | AB + CD → AD + CB | NaOH + HCl → NaCl + H₂O |
