Результаты доступны в кабинете учителя

Общий код доступа больше не используется. Откройте основной сайт → «Войти» → личный кабинет → «Результаты тестов». Там видны только тесты вашего кабинета.

Открыть Учу по ФРП

Для получения результатов создавайте ссылку на тест из своего кабинета. Прохождение обычной страницы без ссылки учителя не отправляет ответы в общую таблицу.
